## Projects

- **[Acqua Analisi / Aqua Intelligence](https://making-lemonade.github.io/cap-acqua-monitor/)** — an independent interactive exploration of public water-quality datasets, with data engineering, geospatial charts and exploratory analytics. [Source repository](https://github.com/making-lemonade/cap-acqua-monitor).
